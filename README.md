# Reto IA Banorte: Agente Conversacional de CV

**Sobre el Proyecto**
Este repositorio contiene la implementación de un agente conversacional diseñado para el Reto IA Banorte. Su objetivo principal es representar mi trayectoria profesional de manera interactiva, permitiendo a los usuarios conocer mi perfil a través de una conversación con un chatbot

**Qué puede responder el agente**
El chatbot está diseñado para extraer información precisa de mi currículum mediante un sistema RAG (Retrieval-Augmented Generation). 

Puedes preguntarle sobre:
* Mi educación
* Mi experiencia laboral
* Mis logros
* Mis habilidades
* Idiomas que hablo
* Mis projectos que he realizado
